# Line Following Robot

Welcome to the Line Following Robot project! This project involves designing a robot that follows a line using an Arduino microcontroller. The robot uses various sensors and control algorithms, including PID control, to navigate along a predefined path.

## Features

- **Line Following**: The robot can follow a black line on a white surface using light sensors.
- **PID Control**: Implemented Proportional-Integral-Derivative (PID) control for smooth and accurate line following.
- **Custom PID**: Custom PID algorithms tailored for specific scenarios.
- **Sensor Integration**: Supports configurations with 4 sensors for precise line detection.
- **Modular Design**: Easy to extend and modify for different robot configurations and control strategies.

## Technologies Used

- **Arduino**: Microcontroller platform used for programming the robot.
- **C++**: Programming language used for coding the robot's behavior.
- **Sensors**: Light sensors for detecting the line.
- **PID Library**: Utilized for implementing PID control algorithms.
